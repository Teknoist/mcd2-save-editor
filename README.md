## 📖 About
**Minecraft Dungeons 2 Save Editor (MCD2)** is the most comprehensive open-source tool for editing your Minecraft Dungeons 2 character files. Whether you want to experiment with different builds, recover lost items, modify enchantments, or adjust your power level, this tool provides a seamless, game-like user interface to do it safely.

Are you tired of grinding for the perfect gear? This save editor allows you to fully customize your character's inventory, loadout, artifacts, and stats.

## 🚀 Features
- **Full Inventory Management:** Add, delete, or clone weapons, armor, and artifacts.
- **Enchantment Editor:** Modify enchantment slots. Choose from Tier I, II, or III enchantments with a UI that identically matches the game and popular databases like Maxroll.
- **Power Level & Rarity:** Upgrade your favorite gear to max power level and change items to **Unique** or **Rare** rarities instantly.
- **Smart Category Filtering:** The UI automatically filters Melee, Ranged, and Armor items so you never apply the wrong enchantments to your gear.
- **Auto-Backup System:** Every time you save, the editor automatically generates a .bak file in your game directory so you never lose your progress.
- **Automatic Save Detection:** Automatically finds your Xbox / Microsoft Store Windows character saves.

## 📥 Download & Installation
1. Go to the [Releases Page](https://github.com/Teknoist/mcd2-save-editor/releases/latest).
2. Download the latest **MCD2.Save.Editor.Setup.exe**.
3. Run the installer. 
4. The application will automatically detect your save files. If you play on Steam, simply click the folder icon to manually select your wgs or save directory.
